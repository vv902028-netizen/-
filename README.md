# Умный Экран (ButtonSaver)

<p align="center">
  <b>Сохранение и замена физической кнопки питания на смартфонах Android при помощи жестов и датчиков.</b>
</p>

---

## 📱 О проекте

Многие устройства (особенно на старых версиях Android или бюджетные модели) со временем страдают от механического износа кнопки питания: она залипает, перестаёт реагировать на нажатия или полностью отваливается. 

**«Умный Экран»** решает эту проблему на уровне программного обеспечения: приложение позволяет включать и выключать экран без единого касания физической кнопки питания, используя встроенные сенсоры движения, датчик приближения и экранные элементы.

---

## ⚡ Ключевые возможности

### 1. Блокировка и пробуждение жестами
- **Встряхивание (Shake to Lock / Wake)**: 
  - Резкое движение телефоном гасит экран (если он включён) либо включает его из спящего режима.
  - 3 фиксированных уровня чувствительности: *Низкая*, *Обычная*, *Высокая*.
- **Датчик приближения (Proximity Wave & Pocket Guard)**:
  - **Wave to wake**: взмах ладонью перед верхней частью экрана или извлечение телефона из кармана включает дисплей.
  - **Cover to lock**: удержание ладони над датчиком на ~1 секунду безопасно выключает экран.
  - **Pocket Guard**: блокирует случайные срабатывания встряхивания и пробуждения, когда телефон находится в кармане или сумке (датчик прикрыт).
- **Плавающий овал двойного тапа (Floating Pill)**:
  - Полупрозрачная круглая/овальная кнопка поверх всех окон, которую можно переместить пальцем в любое удобное место экрана.
  - Двойной тап по ней мгновенно блокирует телефон.
- **Шторка уведомлений и быстрые настройки (Quick Settings)**:
  - Постоянное фоновое уведомление с быстрой кнопкой «Заблокировать».
  - Плитка быстрого доступа в шторку Android (Quick Settings Tile).

### 2. Гибридный механизм блокировки
- **Специальные возможности (Accessibility Service)**: штатное действие `GLOBAL_ACTION_LOCK_SCREEN` (Android 9+). Не сбрасывает разблокировку по отпечатку пальца или лицу.
- **Администратор устройства (Device Administrator)**: вызов `DevicePolicyManager.lockNow()`. Обеспечивает безотказную аппаратную блокировку на старых версиях Android (Android 5.0–8.1) и как надёжный резервный вариант.
- Автоматический выбор оптимального способа блокировки под текущую версию системы.

### 3. Тактильный отклик (Гаптика)
- Мягкая и информативная вибрация при успешном срабатывании жестов, блокировке и переключении тумблеров.

### 4. Спокойный функциональный дизайн
- Строго круглые и овальные формы элементов управления.
- Никаких псевдо-3D эффектов, навязчивых теней и перегруженных анимаций.
- Бережёт заряд аккумулятора за счёт тёмной палитры и умного освобождения WakeLock.

## 🛠 Технический стек

- **Язык**: Kotlin
- **UI Framework**: Jetpack Compose (Material 3)
- **Архитектура**: MVVM + StateFlow + SharedPreferences Repository
- **Фоновые службы**: Android Foreground Service, `SensorEventListener` (акселерометр и датчик приближения), `PowerManager.WakeLock`
- **Системная интеграция**: `DeviceAdminReceiver`, `AccessibilityService`, `TileService`, `WindowManager` Overlay
- **Минимальная версия**: Android 7.0 (API 24+) / совместимость с Android 7.0–14+

## 🚀 Сборка и запуск

### Требования
- Android Studio Hedgehog (или новее) / JDK 17+
- Android SDK 34+

### Команды в терминале:

```bash
# Клонирование репозитория
git clone https://github.com/your-username/smartscreen.git
cd smartscreen

# Сборка debug APK
./gradlew assembleDebug

# Запуск тестов
./gradlew testDebugUnitTest
```

Готовый файл APK будет находиться по пути:
`app/build/outputs/apk/debug/app-debug.apk`

## 🔒 Требуемые разрешения

| Разрешение | Назначение |
|---|---|
| **Специальные возможности** или **Администратор устройства** | Для программного выключения и блокировки экрана без физической кнопки. |
| **Работа в спящем режиме (Исключение из оптимизации батареи)** | Чтобы система Android не отключала сенсоры жестов после выключения экрана. |
| **Поверх других окон (`SYSTEM_ALERT_WINDOW`)** | Для отображения плавающей кнопки двойного тапа. |
| **Уведомления (`POST_NOTIFICATIONS`)** | Для поддержания стабильного Foreground Service и кнопки блокировки в шторке. |
