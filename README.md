## Зачем нужно это приложение

На старых и активно используемых Android-смартфонах механическая кнопка питания часто выходит из строя раньше самого устройства: начинает срабатывать через раз, залипает или вовсе отваливается.

**Умный Экран** переносит управление дисплеем на встроенные сенсоры и системные службы Android:
- работает **полностью локально** (в манифесте отсутствует даже разрешение `INTERNET`);
- поддерживает гибридную блокировку — **Специальные возможности** (Android 9+, сохраняет биометрию) и **Администратор устройства** (надёжная аппаратная блокировка на старых прошивках);
- автоматически восстанавливает фоновую службу после перезагрузки смартфона;
- выполнен в спокойном тёмном стиле с круглыми и овальными элементами управления и мягкой гаптикой.

## Возможности

### Триггеры включения и выключения экрана

| Способ | Выключение (блокировка) | Включение (пробуждение) | Особенности |
|---|:---:|:---:|---|
| **Встряхивание (Shake)** | ✅ | ✅ | 3 уровня чувствительности: *Низкая*, *Обычная*, *Высокая* |
| **Датчик приближения** | ✅ (прикрытие ~1 сек) | ✅ (взмах / извлечение из кармана) | Встроенная защита в кармане (**Pocket Guard**) |
| **Плавающий овал** | ✅ (двойной тап) | — | Перемещается пальцем в любое место, настройка прозрачности (50% / 75% / 100%) |
| **Шторка уведомлений** | ✅ (1 нажатие) | — | Постоянное фоновое уведомление + плитка Quick Settings Tile |

### Гибридный движок блокировки
- **Автовыбор (по умолчанию)**: использует *Специальные возможности*, а если они недоступны — автоматически переключается на *Администратора устройства*.
- **Специальные возможности (`AccessibilityService`)**: системное действие `GLOBAL_ACTION_LOCK_SCREEN` (Android 9+). Не сбрасывает разблокировку по отпечатку пальца, лицу и Smart Lock.
- **Администратор устройства (`DevicePolicyManager`)**: прямой вызов `lockNow()`. Обеспечивает безотказную блокировку на старых версиях Android.

### Гаптика и стабильность
- **Тактильный отклик (`HapticHelper`)**: короткие чёткие виброимпульсы при нажатиях и срабатывании жестов (можно отключить в настройках).
- **Автозапуск после перезагрузки (`BootCompletedReceiver`)**: если служба была включена, она автоматически поднимется после рестарта телефона.
- **Бережный `WakeLock`**: при пробуждении экрана удерживается не дольше 4 секунд и освобождается автоматически.

## Архитектура

Приложение построено по чистой модульной схеме без сторонних сетевых SDK и тяжёлых фреймворков:

```text
┌──────────────────────────────────────────────────────────────────────┐
│                        UI (Jetpack Compose)                          │
│         MainActivity ─── DashboardScreen ─── PillComponents          │
└──────────────────────────────────┬───────────────────────────────────┘
                                   │ Реактивное состояние (StateFlow)
                                   ▼
┌──────────────────────────────────────────────────────────────────────┐
│                       Хранилище настроек                             │
│            PreferencesManager (SharedPreferences + Flow)             │
└──────────────────────────────────┬───────────────────────────────────┘
                                   │ Управление жизненным циклом
                                   ▼
┌──────────────────────────────────────────────────────────────────────┐
│                       Фоновые службы Android                         │
│                                                                      │
│  ┌────────────────────────────┐     ┌─────────────────────────────┐  │
│  │    ScreenControlService    │     │ ScreenLockAccessibilitySvc  │  │
│  │    (Foreground Service)    │     │  GLOBAL_ACTION_LOCK_SCREEN  │  │
│  │ • Акселерометр (Shake)     │     └──────────────┬──────────────┘  │
│  │ • Датчик приближения       │                    │                 │
│  │ • Pocket Guard & WakeLock  │                    ▼ Fallback        │
│  │ • HapticHelper (вибрация)  │     ┌─────────────────────────────┐  │
│  └─────────────┬──────────────┘     │     ScreenAdminReceiver     │  │
│                │                    │   DevicePolicyManager.lock  │  │
│                ▼                    └─────────────────────────────┘  │
│  ┌────────────────────────────┐                                      │
│  │   FloatingOverlayManager   │     ┌─────────────────────────────┐  │
│  │  (Плавающий овал тапа)     │     │   BootCompletedReceiver /   │  │
│  └────────────────────────────┘     │       LockTileService       │  │
│                                     └─────────────────────────────┘  │
└──────────────────────────────────────────────────────────────────────┘
```

### Стек технологий
- **Язык**: Kotlin
- **UI**: Jetpack Compose + Material 3 (собственная спокойная тёмная тема без динамических цветов Material You)
- **Состояние**: `StateFlow` + `SharedPreferences`
- **Тесты**: JUnit 4 + Robolectric
- **Совместимость**: `minSdk 24` (Android 7.0) — `targetSdk 36`

## Системные разрешения и приватность

Приложение **не запрашивает доступ к интернету** и не содержит аналитики, рекламы или телеметрии. Подробнее о политике безопасности читайте в [SECURITY.md](SECURITY.md).

| Разрешение | Обязательно | Назначение |
|---|:---:|---|
| **Специальные возможности** *или* **Администратор устройства** | Да (одно из) | Программное выключение и блокировка экрана |
| `WAKE_LOCK` | Да | Кратковременное пробуждение экрана по жесту |
| `FOREGROUND_SERVICE` / `FOREGROUND_SERVICE_SPECIAL_USE` | Да | Стабильная работа слушателя сенсоров при погашенном экране |
| `POST_NOTIFICATIONS` | Рекомендуется | Постоянное уведомление с быстрой кнопкой «Заблокировать» |
| `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` | Рекомендуется | Защита службы от остановки системой энергосбережения |
| `SYSTEM_ALERT_WINDOW` | По выбору | Только при включении плавающего овала двойного тапа |
| `RECEIVE_BOOT_COMPLETED` | Автоматически | Восстановление работы службы после перезагрузки устройства |
| `VIBRATE` | Автоматически | Тактильный виброотклик (гаптика) |

## Сборка и запуск

### Требования
- **JDK**: 17+ (в Android Studio идёт в комплекте)
- **Android Studio**: Ladybug / Meerkat или новее (либо Android SDK Command-line Tools)
- **Android SDK**: API 36

### 1. Клонирование
```bash
git clone https://github.com/<ваш-логин>/<имя-репозитория>.git
cd <имя-репозитория>
```

### 2. Создание локального `debug.keystore` (один раз)
Файл `debug.keystore` не хранится в Git по соображениям безопасности (указан в `.gitignore`). Перед первой локальной сборкой создайте стандартный отладочный ключ в корне проекта:

```bash
keytool -genkey -v -keystore debug.keystore \
  -storepass android -alias androiddebugkey \
  -keypass android -keyalg RSA -keysize 2048 -validity 10000 \
  -dname "CN=Android Debug,O=Android,C=US"
```

### 3. Сборка и тестирование
```bash
# Запуск модульных и Robolectric-тестов
./gradlew testDebugUnitTest

# Сборка Debug APK
./gradlew assembleDebug
```

Готовый APK появится по пути:
```text
app/build/outputs/apk/debug/app-debug.apk
```

### 4. Сборка Release APK (с подписью)
Для релизной сборки передайте параметры вашего upload-ключа через переменные окружения:
```bash
KEYSTORE_PATH=/path/to/my-upload-key.jks \
STORE_PASSWORD=your_store_password \
KEY_PASSWORD=your_key_password \
./gradlew assembleRelease
```

## Стабильная работа в фоне (MIUI, Samsung, Honor)

Некоторые производители агрессивно завершают фоновые службы и датчики после выключения экрана. Для бесперебойной работы:
1. На главном экране приложения нажмите **«Разрешить»** напротив пункта **«Работа в спящем режиме»**.
2. **Xiaomi (MIUI / HyperOS)**: *Настройки → Приложения → Умный Экран → Автозапуск* (вкл.) и *Контроль активности → Нет ограничений*.
3. **Samsung (One UI)**: *Настройки → Батарея → Ограничения в фоновом режиме → Приложения в неограниченном режиме → добавить «Умный Экран»*.
4. **Huawei / Honor (EMUI / MagicOS)**: *Настройки → Батарея → Запуск приложений → Умный Экран → Управление вручную* (включить все 3 тумблера).
5. **Oppo / Realme / OnePlus (ColorOS / OxygenOS)**: разрешить фоновую активность и автозапуск в свойствах приложения.
