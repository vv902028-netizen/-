# Политика безопасности и приватности (Security & Privacy)

Приложение **Умный Экран (ButtonSaver)** использует системные механизмы Android (`AccessibilityService` и `DeviceAdminReceiver`), поэтому прозрачность работы с данными является главным приоритетом.

## Гарантии приватности

- **Полная автономность**: в `AndroidManifest.xml` отсутствует разрешение `android.permission.INTERNET`. Приложение технически не способно отправлять данные в сеть.
- **Минимальные права `AccessibilityService`**:
  - `android:canRetrieveWindowContent="false"` — служба **не имеет права читать содержимое экрана**, нажатия клавиш, пароли или текст в других приложениях.
  - Метод `onAccessibilityEvent` не обрабатывает никакие события.
  - Служба используется исключительно для вызова системного действия `GLOBAL_ACTION_LOCK_SCREEN`.
- **Минимальные политики `DeviceAdminReceiver`**:
  - В `res/xml/device_admin.xml` объявлена только одна политика: `<force-lock />`.
  - Приложение не запрашивает прав на сброс настроек, смену пароля или шифрование хранилища.
- **Локальное хранение**: настройки сохраняются исключительно в приватном `SharedPreferences` приложения на устройстве.

## Сообщение об уязвимостях

Если вы обнаружили проблему безопасности в коде приложения:
1. Не публикуйте детали уязвимости в открытых Issues до её исправления.
2. Откройте приватное уведомление через вкладку **Security → Advisories** на GitHub (если включено) либо свяжитесь с сопровождающими репозитория напрямую.
3. Укажите версию приложения, версию Android и подробное описание проблемы.
