# Участие в разработке (Contributing)

Спасибо за интерес к проекту **Умный Экран (ButtonSaver)**! Любые баг-репорты, улучшения стабильности на разных прошивках Android и Pull Request'ы приветствуются.

## Принципы проекта

1. **Приоритет — стабильность и энергоэффективность**: датчики и `WakeLock` не должны разряжать батарею или вешать систему.
2. **100% оффлайн и приватность**: не добавляйте разрешение `INTERNET`, аналитику, трекеры и сторонние сетевые библиотеки.
3. **Спокойный интерфейс**: придерживайтесь плоского тёмного стиля с круглыми и овальными формами (`CircleShape` / `PillShape`) без лишних анимаций и псевдо-3D эффектов.
4. **Совместимость**: все новые функции должны корректно работать начиная с `minSdk = 24` (Android 7.0) и учитывать ограничения современных версий Android (Foreground Services, runtime-разрешения).

## Как предложить изменение

1. Сделайте Fork репозитория и создайте ветку от `main`:
   ```bash
   git checkout -b fix/your-change-name
   ```
2. Если вы собираете проект локально впервые, создайте `debug.keystore` (см. инструкцию в [README.md](README.md)).
3. Внесите изменения, следуя правилам форматирования из `.editorconfig`.
4. Проверьте сборку и тесты перед отправкой:
   ```bash
   ./gradlew testDebugUnitTest
   ./gradlew assembleDebug
   ```
5. Откройте Pull Request, заполнив шаблон описания.

## Сообщения об ошибках

Если вы обнаружили проблему (например, служба выгружается на конкретной модели телефона или не срабатывает датчик приближения), откройте [Issue](.github/ISSUE_TEMPLATE/bug_report.md) и укажите:
- модель устройства и версию Android / прошивки;
- выбранный метод блокировки (*Специальные возможности* / *Администратор* / *Автовыбор*);
- шаги воспроизведения.
